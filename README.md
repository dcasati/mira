# Mira

AI copilot for frontline radio operations. This repo will be populated by
merging the following previously-separate repositories:

- `services/mira-gateway/` — Zello push-to-talk radio gateway (Go)
- `services/operator-agent/` — Ontology-grounded operator agent (Python, Foundry hosted + AKS variants)
- `ontology-governance/` — Fabric ontology -> GitHub -> Azure Managed Redis governance pipeline
